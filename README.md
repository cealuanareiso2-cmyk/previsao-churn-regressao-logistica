# 📊 Previsão de Churn com Regressão Logística

Este projeto utiliza inteligência artificial para prever se um cliente de uma empresa de telecomunicações irá cancelar o serviço (Churn). 

## 🎯 Objetivo de Negócio
Identificar clientes em risco para que a empresa possa oferecer benefícios e retê-los, reduzindo a perda de receita.

## 🛠️ Ferramentas Utilizadas
- **Linguagem:** Python
- **Bibliotecas:** Pandas, Scikit-Learn, Matplotlib, Seaborn
- **Modelo:** Regressão Logística (Logistic Regression)

## 📁 Estrutura do Repositório
- `dados/`: Contém a base de dados de clientes.
- `notebooks/`: O código passo a passo do treinamento do modelo.
- `modelos/`: O cérebro do robô (modelo treinado) salvo para uso futuro.

## 🚀 Como visualizar
Basta abrir a pasta `notebooks` e clicar no arquivo `.ipynb` para ver todas as análises e gráficos diretamente aqui no GitHub!
